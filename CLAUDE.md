# CLAUDE.md

## Stack
- Node.js (LTS)
- Visual Studio Code
- Git + GitHub
- Claude Code extension

## Conventions
- Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/).
- Documentation updates use `docs:` prefix.
- Setup or tooling changes use `chore:` prefix.
- New features use `feat:` prefix.

## AI Usage
- Claude Code is used to critique documentation and suggest improvements.
- AI feedback is applied directly to project files before committing.
